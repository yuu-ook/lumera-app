# CLI Talk

CLI にチャット画面から指示を出すためのツールです。トーク（部屋）ごとに CLI を 1 つつなぎ、
メッセージを送るとその CLI が動いて、返事が吹き出しで返ってきます。

- **Claude Code トーク** — 日本語で指示。同じトーク内では会話が継続されます（`claude -p --resume`）
- **シェル トーク** — 送った文をそのままコマンドとして実行。`cd` も次のメッセージに引き継がれます

依存パッケージはありません（Node.js 18 以上）。Claude Code トークには `claude` コマンドが必要です。

## 使い方

```bash
npm run talk            # または: node cli-talk/server.js
```

表示された `http://127.0.0.1:8787/?token=...` をブラウザで開き、「＋」でトークを作成します。

### スマホから使う

```bash
HOST=0.0.0.0 npm run talk
```

同じ Wi-Fi のスマホで、表示された URL を開きます。**この URL を知っている人は PC 上で
コマンドを実行できる**ので、信頼できるネットワーク以外では使わないでください
（外出先から使うなら Tailscale などの VPN 経由がおすすめです）。

## 設定（環境変数）

| 変数 | 既定値 | 内容 |
| --- | --- | --- |
| `PORT` | `8787` | ポート番号 |
| `HOST` | `127.0.0.1` | 待ち受けアドレス |
| `CLI_TALK_CWD` | 起動したフォルダ | 新しいトークの作業フォルダ初期値 |
| `CLI_TALK_TOKEN` | 自動生成 | アクセストークン |
| `CLI_TALK_DATA` | `cli-talk/data` | 履歴とトークンの保存先 |
| `CLAUDE_BIN` | `claude` | Claude Code のコマンド |

## 権限モード

チャットからは「このコマンドを実行していい？」という都度の確認に答えられないため、
トークごとにあらかじめ権限モードを選びます。既定は「ファイル編集を自動許可」です。
シェルコマンドなども確認なしで実行させたい場合は、設定（⋯）から変更できます。

## 操作

- Enter で送信、Shift+Enter で改行（スマホは送信ボタン）
- 実行中は ■ で停止。実行中に送ったメッセージは順番待ちになります
- ⋯ からトーク名・作業フォルダ・権限モードの変更、会話のリセット、削除
